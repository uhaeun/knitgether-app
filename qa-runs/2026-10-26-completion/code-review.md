부모 CAS는 정확한 밀리초 버전을 비교하고 성공한 요청만 자식을 변경한다. 자식 경로의 잠금 순서는 부모→자식으로 통일했다. 검증 실패 시 버전 증가도 SQL과 함께 롤백한다. 새 파일은 클라이언트가 기존 storage key를 지정할 수 없는 UUID 경로로 쓰며, 물리 정리는 트랜잭션 종료 뒤 참조를 재확인한다. cleanup 실패는 커밋 성공을 HTTP 실패로 바꾸지 않고 durable marker로 재시도한다. 새 마이그레이션·외부 패키지·운영 설정 변경은 없다.

계정/프로젝트별 메모 초안 경로, 저장/버리기/프로젝트 삭제 시 정리, 충돌 중 유지, 자동 서버 저장 없음도 대조했다. UI-03에 해당하는 화면과 cm 계산 소스는 본 수정에서 바꾸지 않았다. 단위/API/실제DB/시뮬레이터 결과는 서로 대체하지 않는다.

범위: 실 사용량·사진·재료 연결 테이블은 전체 SaveProjectDto에 포함되지 않아 강제로 부모 버전을 묶지 않았다. 실제 API 생성→전체 저장→SQL/파일 동일 검사를 추가했다. 게이지 관련 별도 테이블도 전체 저장 코드의 쓰기 대상에 없음을 정적으로 확인했다. 재고 자체의 모든 동시 차감, 장시간 부하, 모든 파일/계정 전환 조합, 과거 고아 파일 일괄 정리는 본 리뷰의 전수 보장 범위가 아니다.

로컬 실제DB40·서버147·API75·Swift359 및 최종 UI-03 24 PASS. 원격 CI의 판정과 병합 사실은 PR48 최종 head의 Checks·merge event 및 전달 RESULTS.md를 따른다. 미해결 코드 리뷰 차단 항목은 없으며 UI/CI 완료 전에는 병합하지 않는다.
