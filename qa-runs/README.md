날짜별 보고서는 해당 시점의 상태다. 과거 FAIL과 커밋 전 로컬 판정을 나중 결과로 덮어쓰지 않는다. 마지막 후속 보고서에서 현재 범위와 잔여 결함을 확인한다. 사용자 수용 기준과 Codex의 구현·실행을 각 보고서에 구분한다.
