# PDF 테스트 자료

이 폴더의 PDF는 페이지 이동, 도안 교체, 드로잉 유지 여부를 확인하기 위해 만든 격자 자료입니다. 실제 뜨개 도안이나 제작 안내가 아닙니다. 각 페이지에 파일명에 대응하는 제목, 페이지 번호, 고유 표식을 넣었습니다.

| 파일 | 페이지 수 |
| --- | --- |
| sample1.pdf | 11 |
| sample2.pdf | 9 |
| sample3.pdf | 3 |
| sample4.pdf | 17 |

2026-10-04에 기존 파일을 자체 생성한 테스트 자료로 교체했습니다. 기존 테스트의 파일 참조와 페이지 범위를 유지하기 위해 파일명과 페이지 수는 보존했습니다. 이 날짜 이전의 화면과 실행 기록은 교체 이전 자료를 사용한 기록입니다.

생성 코드는 [make_sample_patterns.py](../../../qa/appium/make_sample_patterns.py)입니다. 저장소 루트에서 `python qa/appium/make_sample_patterns.py`로 다시 생성할 수 있으며 `reportlab`이 필요합니다.
