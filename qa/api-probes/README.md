# 과거 API 진단 스크립트

두 스크립트는 초기 서버 동작을 조사하기 위한 기록입니다. 현재 회귀 실행은 [API 테스트](../api-tests/README.md)를 사용합니다.

| 파일 | 성격 |
|---|---|
| sync08_regression.sh | 이전 PATCH 계약에서 작업 세션 보존을 확인하던 스크립트. 현재 필수 기준 시각을 보내지 않아 거부될 수 있습니다. 요청이 거부됐는데 보존 성공으로 판정하지 않도록 HTTP 200 조건을 추가했습니다. |
| newapi_smoke.sh | 요청과 응답을 출력하는 진단용 스크립트. 출력만으로 통과를 판정하지 않으며 현재 서버 계약의 전체 검증 수단이 아닙니다. |

실행하면 테스트 데이터를 생성하거나 변경합니다. 이번 저장소 검토에서는 문법만 확인했으며 서버 요청을 실행하지 않았습니다.
