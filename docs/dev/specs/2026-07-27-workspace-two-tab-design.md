# 작업 공간 2탭 분리 + 내 뜨개 "정보 보기" — 설계

작성: 2026-07-27 · 상태: 설계 확정 (구현 전)

## 문제
프로젝트 작업 공간(`ProjectWorkspaceView`)이 12개 섹션을 한 세로 스크롤에 모두 쌓아 정보 과부하다. 뜨는 중 실제로 쓰는 건 카운터·도안·행안내·타이머 정도인데, 요약·사진·재료·게이지·메모·스킬까지 항상 함께 노출된다.

## 설계

### 1. 작업 공간 2탭
- **헤더**(`ProjectWorkspaceHeaderView`)는 탭 위에 항상 고정.
- 헤더 아래 세그먼트 컨트롤: `[ 뜨는 중 ] [ 프로젝트 정보 ]`.
- **뜨는 중** 탭: `displayModePicker` · `mainWorkspaceArea`(카운터+도안+행안내) · `ProjectWorkTimePanelView`.
- **프로젝트 정보** 탭: `ProjectWorkspaceSummaryView`(프로젝트 요약) · 진척사진 · 실사용 · 바늘 · 도구 · 게이지 · 메모 · 관련스킬.

### 2. 기본 탭 / 딥링크
- 일반 진입(카드 탭) → **뜨는 중**으로 시작.
- `ProjectWorkspaceView`에 `initialTab: WorkspaceTab = .working` 파라미터 추가. 선택 상태는 화면 로컬 `@State`(열 때마다 initialTab로 시작).

### 3. 내 뜨개 카드 "정보 보기"
- `MyKnittingView` 프로젝트 카드의 기존 `.swipeActions(edge: .trailing)`에 **"정보 보기"** 액션 추가(왼쪽으로 스와이프 = trailing edge).
- 누르면 해당 프로젝트 작업 공간을 `initialTab = .info`(프로젝트 정보 탭)로 연다.
- 결과: 프로젝트 요약은 평소엔 안 보이고, "정보 보기"로만 도달.

## 동작 요약
| 경로 | 결과 |
|---|---|
| 카드 탭 | 작업 공간 → 뜨는 중 탭 |
| 카드 왼쪽 스와이프 → 정보 보기 | 작업 공간 → 프로젝트 정보 탭 |
| 작업 공간 안 세그먼트 | 두 탭 자유 전환 |

## 테스트 / 리스크
- 기존 워크스페이스 UI 테스트(카운터·행안내·작업세션)가 다루는 섹션은 전부 **뜨는 중(기본 탭)**에 있어 그대로 통과 예상 → POM 수정 불필요(POM은 하은님 영역).
- 구현 후 `testWorkspaceRowCounter*` · `testWorkspaceRowInstruction*` · `testWorkspaceWorkSession*` 3계열 재실행으로 확인.
- 정보 탭에만 있는 패널(실사용·게이지 등)은 현재 워크스페이스 UI 테스트가 없어 영향 없음.

## 4. 간소화 (2026-07-27 추가, 하은님 승인)

### 4-1. 프로젝트 요약 슬림 (8줄 → 4줄)
- 남김: 진행(카운터 n/m단) · 일정(목표일) · 시작일 · 총 작업시간
- 제거(중복): 화면구성(=보기모드) · 도안 · 재료 · 실사용(=각 패널) · 행안내 · 서버저장(=헤더 배지)

### 4-2. 워크스페이스 헤더 슬림
- 남김: 제목 · 상태배지 · (sync 배지) · 별 · 최근 작업
- 제거: 시작일 · 총작업시간 → 4-1 요약으로 이관 (총작업시간은 타이머 패널과도 중복)
- schedule(목표일) 라벨도 요약의 '일정'과 겹치므로 헤더에서 제거

### 4-3. 동기화 배너 공용화 + 톤다운
- 현재 `계정 저장 확인이 필요한 …/다시 시도` 배너가 10개 화면(Home·Library 5종·MyKnitting·WorkspaceHeader·PatternLibrary·DocumentScanner)에 복붙됨.
- 공용 컴포넌트 `SyncRetryBanner`로 추출 → 컴팩트 스타일(작은 텍스트 + 작은 재시도 버튼) → 10곳 교체.
- 효과: 시각 톤다운 + 중복 제거. **별도 커밋**(워크스페이스 변경과 분리).

## 범위 밖 (이번엔 안 함)

- 탭 선택 기억(마지막 본 탭 유지).
- 내 뜨개 카드 칩 정리 (하은님이 의도한 정보라 유지).
