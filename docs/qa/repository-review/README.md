## 수정한 내용

1. 제출용 요약과 상세 QA 기록의 읽기 순서를 분리하고 전체 목차를 추가했습니다.
2. 과거 설계와 개발 문서에 기준 시점 안내를 붙였습니다. 사라진 원문은 검증한 Git 이력 링크로 연결했습니다.
3. 비공개 작업 문서를 가리키던 링크와 Appium 폴더 이동으로 깨진 링크를 정리했습니다.
4. 1차 설계 22건과 수동 수행 21건을 구분했습니다. 수정 후 PASS가 포함된 집계를 최초 결과처럼 쓰지 않도록 했습니다.
5. “검출률 100%”, “모든 API 판정에서 SQL 조회”와 단독 코드 작성으로 읽히는 역할 표현을 바로잡았습니다.
6. API 안내를 현재 20개 파일에 맞추고, 오래된 충돌 감지 설명을 수정했습니다.
7. Postman 생성 요청에 현재 서버가 요구하는 프로젝트 ID, 카운터와 기타 필수값을 추가했습니다.
8. UI-51에서 빈 도안 본문을 정상으로 비교하는 상황을 차단하고, 페이지 이동과 사전 화면 종료를 확인하도록 했습니다.
9. 결함 주입 도구가 기존 편집 파일을 되돌릴 수 있는 경로와 ERROR를 검출 성공으로 집계하는 문제를 수정했습니다. 다른 서버 프로세스를 강제 종료하는 동작도 제거했습니다.
10. 과거 API 진단 스크립트가 거부된 PATCH 요청을 보존 성공으로 판정하지 않도록 조건을 보완했습니다.
