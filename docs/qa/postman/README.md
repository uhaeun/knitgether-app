# Postman 요청 모음

[컬렉션 파일](knitgether-local.postman_collection.json)은 기본 API 요청 12개를 담습니다. 전체 API 테스트케이스 29개를 자동 실행하는 컬렉션은 아닙니다. 상세 검증은 [API 테스트](../../../qa/api-tests/README.md)와 [API 및 네트워크 기록](../portfolio/07_api_and_network.md)에 있습니다.

1. Postman에 컬렉션을 가져옵니다.
2. 테스트 서버 주소를 `baseUrl`에 입력합니다.
3. 개발 또는 테스트 모드의 공개 기본 토큰을 사용하거나, 테스트 계정으로 로그인한 뒤 응답의 `accessToken`을 `token`에 입력합니다. 계정과 실제 토큰은 저장소에 올리지 않습니다.
4. 프로젝트 생성 요청의 응답 코드와 반환 ID를 확인하고, 목록 및 DB에서 같은 ID의 저장 결과를 대조합니다.

프로젝트 생성은 매번 새 프로젝트 ID와 카운터 ID를 만듭니다. 재전송을 확인하려면 동일 ID를 고정한 별도 요청이 필요합니다. 생성한 테스트 데이터는 확인 후 정리합니다.

2026-10-04에 프로젝트 생성 예시의 필수값을 현재 서버 DTO에 맞췄습니다. 요청 생성 스크립트와 DTO 검증을 오프라인으로 확인했으며, 이번 수정본을 실제 서버로 전송한 결과는 아닙니다. 기존 스크린샷은 당시 실행 증거로 보존합니다.
