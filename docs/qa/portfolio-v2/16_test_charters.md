> 2026-09-18 신설. 8월 원본(`docs/qa/portfolio/00~15`)에 없던 문서다. 탐색 관찰을 당시에는 차터 형식으로 남기지 않았다. 원본 06(관찰 39건 분류와 부록 메모), 10(발견 시점 열의 "탐색 관찰" 표기), 14(관찰 분류와 오탐 정정), `docs/qa/portfolio/evidence/0727_manual_verification/README.md`에 남은 기록에서 세션을 골라 차터 칸에 옮겼다. 기록에 없는 칸은 "기록 없음"으로 둔다.

#### 이 문서의 위치

ISTQB 4.0 테스트 프로세스의 설계 활동 산출물이다. 4.0은 탐색적 테스팅을 경험 기반 기법으로 분류하고, 세션 기반으로 수행할 때 테스트 목표를 적은 테스트 차터로 세션을 이끈다고 설명한다. 00의 문서 매핑 표에서 이 문서를 설계 활동의 테스트 차터 자리에 두었다. 스크립트 케이스는 05와 09가, 탐색에서 나온 결함의 판정과 계보는 10이 맡는다.

차터는 원래 세션 전에 쓴다. 여기 차터는 세션 뒤의 기록에서 재구성한 것이다. 그래서 미션 칸에는 사전에 정한 목표가 아니라 기록에 남은 출발점을 적었다. 이 차이를 흐리지 않으려고 칸 이름을 "출발점"으로 둔다.
