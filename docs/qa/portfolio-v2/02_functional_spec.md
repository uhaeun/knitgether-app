# 02_기능 동작 정의서

> 2026-09-18 재작성, 2026-09-19 원본 v2.5(9/15) 반영. SPEC 48건의 동작 정의와 코드 일치 판정은 원본(`docs/qa/portfolio/02`, 문서 이력 v2.5)을 그대로 옮겼다. 바뀐 것은 배치다. 판정 체계와 추적 구조를 SPEC 목록 앞으로 빼고, 근거 열은 대표 파일:라인만 남겼다. 근거 전체와 판정 경위 원문은 원본에 있다.

#### 이 문서의 위치

ISTQB 4.0 테스트 프로세스의 분석 활동 산출물이다. 분석 활동은 테스트 베이시스를 읽고 테스트 조건을 뽑는 일이다. 01이 무엇을 베이시스로 삼을지 정했고, 이 문서는 그 베이시스에서 판정 가능한 동작 문장을 뽑아 SPEC ID를 붙인다. SPEC 한 행이 테스트 조건 하나이고 기대 결과를 함께 담는다. 29119-3 산출물로는 테스트 조건 목록과 추적성 정보에 해당한다.

원본은 이 문서를 검증 기준선(test basis)이라고 불렀다. ISTQB 용어로 엄밀히 나누면 베이시스는 인수인계 문서, 코드, 기획서이고(01의 1절) 이 문서는 거기서 뽑은 테스트 조건이다. 05 이후의 모든 판정이 이 문서를 인용하므로 실행 단계에서는 이 문서가 판정 기준 역할을 한다. 우선순위 등급은 03, 테스트 케이스는 05가 맡는다.

#### 1. 작성 원칙

- 개발 전에 쓰는 기능명세서가 아니다. 개발이 끝난 뒤 QA가 관찰 가능한 동작을 판정 가능한 문장으로 적은 것이다.
- 원천은 QA 인수인계 문서와 현재 코드다. 사전 기획 문서는 데이터 구조가 전면 변경돼 의도 참고용으로만 쓴다.
- 코드에서 역산하되 코드를 정답으로 삼지 않는다. 코드 동작을 기준으로 승인할지 불일치로 기록할지는 기획자 관점에서 항목마다 판정했다.
- 근거 열의 파일:라인은 전부 기준 커밋 `bf2b001` 시점이다. 2차 사이클 이후 SPEC은 구현 커밋을 근거로 적었다.
- 범위는 기능 동작이다. 성능, 보안, 접근성은 04의 범위 판단에 따라 뺐다. 인증(SPEC-AUTH)은 보안 항목이 아니라 데이터 정합성 관점의 기능 동작으로 다룬다.
- 합격과 불합격은 여기서 정하지 않는다. 판정은 06 실행에서 한다.

#### 2. 코드 일치 판정 5단계

각 SPEC에 코드와 대조한 결과를 붙였다. 실행 전에 한 대조이므로 ISTQB의 정적 테스트에 해당한다.

| 판정 | 뜻 | 확정 시점 |
| --- | --- | --- |
| 일치 | 관찰된 코드 동작을 기획 의도와 대조한 뒤 기준으로 채택했다 | 정적 대조 |
| 조건부 일치 | 조건을 달아 채택했다 | 정적 대조 |
| 불일치 의심 | SPEC과 코드가 어긋나 보인다 | 06 실행에서 확정 |
| 불일치 확정 | 코드 구조만으로 어긋남이 확정됐다 | 정적 대조 |
| 미대조 | 기획자가 정의한 기대이나 코드 대조를 하지 않았다 | 06 실행에서 확인 |

일치는 코드를 테스트 오라클로 확정했다는 뜻이 아니다. 오라클이 코드 자체면 코드가 틀려도 테스트가 통과한다. 그래서 코드 동작은 기획 의도와 대조한 뒤에만 기준으로 채택했고, 대조에서 어긋난 것이 불일치 항목이다.

1차 사이클 실행 전에 불일치 의심 8건을 식별했다(v1.2, 29건 기준). 42건 기준 분포는 12의 2절에 있다.

#### 3. 추적 구조

SPEC은 요구사항 추적의 가운데 층이다. 상위는 01의 CUJ와 치명도 축, 하위는 05의 테스트 케이스다. 05의 모든 TC가 SPEC ID를 참조하고, 요구사항에서 실행 결과까지의 전체 매트릭스는 05에서 조립해 06의 판정과 잇는다.

| 상위 (01) | 관련 SPEC |
| --- | --- |
| CUJ-1 첫 사용, 경로 동등성 | PAT-01, PAT-02, SYNC-01~03, CNT-01~02 |
| CUJ-2 재방문, 보존 | SYNC-04~05, SYNC-07, CNT-02, AUTH-02 (AUTH-01은 07 이관) |
| CUJ-2 보강 (작업 시간 정확성, 입력 상한) | TIME-02~03, PROJ-02 |
| CUJ-3 모르는 기술 만남, 맥락 보존 | CNT-02, PAT-02, PAT-05 |
| 연결의 생애주기 (CUJ 아님, 정합성 심층) | LINK-01~05, PAT-04, SYNC-06 |
| CUJ 밖 악조건 (치명도 1~3위 심층) | SYNC-08~11, CNT-03, AUTH-04~06 |
