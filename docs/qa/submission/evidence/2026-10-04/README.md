# 도안 교체와 페이지 복귀 화면

2026-10-04 후속 자동화에서 촬영한 원본 중, 도안 교체와 페이지 복귀를 대조할 수 있는 10장을 남겼습니다. 화면 파일을 편집하거나 결과 문구를 덧그리지 않았습니다.

## 실행 조건

- iPhone 17 Pro Max 시뮬레이터, iOS 26.5, 설치 앱 KnitGether 1.0 (1)
- Appium 3.1.2·XCUITest. 로컬 저장 모드이며 서버 동기화는 시험하지 않았습니다.
- 직접 만든 PDF A 4페이지와 PDF B 2페이지를 사용했습니다.
- 새 빌드를 완료하지 못해 기존 설치 앱을 사용했습니다. 설치 앱의 소스 커밋은 미확정이며 현재 소스의 통과 근거로 확대하지 않습니다.
- 후속 자동화의 실행·촬영에는 AI를 활용했습니다. 최초 수동 수행과 구분합니다.
