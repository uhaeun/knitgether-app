# 뜨개더 QA 포트폴리오

## 읽는 순서

1. **[제출용 PDF](../../../output/pdf/knitgether_qa_portfolio.pdf)**: 프로젝트와 역할, 테스트 전략, 상세 사례 5개, 결과와 회고를 담은 12쪽 문서입니다.
2. **[웹 본문](portfolio.md)**: PDF와 같은 내용을 GitHub에서 읽을 수 있습니다. 사진을 누르면 원본이 열립니다.
3. **[추가 검증 증거](evidence/2026-10-04/README.md)**: Appium으로 촬영한 원본 화면, 검사 결과와 실행 환경입니다.
4. **[상세 QA 기록](../portfolio/README.md)**: 테스트 조건, 수행 결과, 결함과 수정 이력입니다.

PDF와 본문에는 사진 8장이 포함돼 있습니다. PDF는 읽기 순서에 맞춰 사진을 묶어 배치하며, 본문과 검증 결과는 같습니다.

## 기록의 범위

기존 QA 수행 이력과 2026-10-04의 추가 촬영을 구분했습니다. 과거 기록의 링크는 해당 시점의 커밋에 고정했고, 추가 촬영은 별도의 환경과 실행 로그를 연결했습니다.

## PDF 갱신

본문의 정본은 `portfolio.md`입니다. `tools/build_pdf.py`는 이 파일을 읽어 PDF를 생성하며 본문을 덮어쓰지 않습니다. Python과 ReportLab, 한글 TrueType 글꼴이 필요합니다. macOS 기본 경로에 글꼴이 없으면 `KG_KOREAN_FONT`에 사용할 글꼴 경로를 지정합니다.

저장소 루트에서 실행합니다.

```sh
python3 docs/qa/submission/tools/build_pdf.py
```

출력 후에는 모든 페이지를 이미지로 변환해 글자와 표가 잘리거나 사진이 분리되지 않았는지 확인합니다.
