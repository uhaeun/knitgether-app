# POM 화면 목록과 성공/실패 기준 - 2026-07-19

## 목적

이 문서는 XCUITest POM 자동화에서 어떤 화면을 검증 대상으로 삼고, 각 화면을 어떤 기준으로 PASS/FAIL 처리하는지 정의한다. 테스트를 많이 만드는 것보다 먼저 "무엇을 보면 정상이라고 판단할 수 있는지"를 고정하는 QA 산출물이다.

## 공통 판정 규칙

| 구분 | 기준 |
|---|---|
| PASS | 사용자의 액션 후 기대한 화면, 버튼, 문구, 저장 결과가 제한 시간 안에 보인다. |
| FAIL | 기대 요소가 제한 시간 안에 나타나지 않거나, 잘못된 오류 메시지/상태가 보인다. |
| ENV_ISSUE | 서버 미실행, 시뮬레이터 대상 없음, 네트워크 연결 문제처럼 앱 기능 판단과 분리해야 하는 환경 문제가 원인이다. |
| NEED_SPEC_CONFIRM | 정상 동작 기준이 제품 요구사항에 아직 명확하지 않다. |

실패 시에는 XCUITest가 자동으로 실패 화면 스크린샷을 남긴다. 수동 QA 증거는 `docs/qa/portfolio/evidence/`에 저장한다.

## POM 화면 목록

| POM | 화면/역할 | 성공 기준 | 실패 기준 |
|---|---|---|---|
| `KnitGetherUITestCase` | 테스트 실행 공통 설정 | 앱이 foreground 상태로 실행되고, 실패 시 스크린샷이 첨부된다. | 앱 실행 실패, 서버 URL 주입 실패, 실패 증거 미수집. |
| `OnboardingPage` | 온보딩 시작/스킬 테스트 진입 | `다음`, `스킬 테스트 시작`, `시작` 버튼을 통해 메인 탭으로 이동한다. | 다음 단계 버튼이 없거나 메인 탭 진입 전 멈춘다. |
| `AuthPage` | 회원가입/로그아웃 | 회원가입 후 `회원가입이 완료됐어요.` 또는 로그인 상태가 보인다. | 회원가입 버튼/입력칸이 없거나 저장 후 로그인 상태가 아니다. |
| `SkillTestPage` | 온보딩 스킬 테스트 | 스킬 선택 후 저장하면 온보딩의 스킬 테스트 단계로 돌아온다. | 403 `SYSTEM_SKILL_READ_ONLY`, 저장 실패 문구, 또는 이전 화면 복귀 실패. |
| `MainTabBarPage` | 메인 탭 | `내 뜨개` 탭이 보이고, `내 뜨개`와 `도구` 탭 이동이 가능하다. | 탭이 없거나 탭 이동 후 목표 화면을 찾지 못한다. |
| `MyKnittingPage` | 내 뜨개 목록 | 프로젝트 저장 후 성공 메시지 또는 생성한 프로젝트명이 보이고, 재실행 후에도 생성한 프로젝트명이 보인다. | 저장 후 목록에 프로젝트가 없거나 재실행 후 프로젝트가 사라진다. |
| `ProjectFormPage` | 프로젝트 생성 폼 | 프로젝트명을 입력하고 저장 버튼을 누를 수 있다. | 입력칸/저장 버튼이 없거나 저장 액션이 발생하지 않는다. |
| `ToolPage` | 도구 목록 | 게이지 계산기 진입 버튼을 찾고 이동한다. | 도구 카드 또는 진입 버튼을 찾지 못한다. |
| `GaugeCalculatorPage` | 게이지 계산/저장 | 필수 수치를 입력하고 `세탁 전 게이지를 저장했어요.` 문구가 보인다. | 입력 불가, 저장 버튼 비활성, 저장 성공 문구 미노출. |
| `UITestPage` | POM 공통 액션 | 버튼/입력칸을 기다리고, 키보드와 스크롤 상태를 처리한다. | 요소가 존재하지만 누를 수 없는 상태가 계속된다. |

## 화면별 추가 수동 QA 기준

| 화면 | 우선순위 | 수동 확인 기준 |
|---|---|---|
| 회원가입/로그인 | P0 | 신규 가입, 중복 이메일, 잘못된 비밀번호, 서버 OFF 오류 메시지를 확인한다. |
| 온보딩 | P0 | 앱 재설치 후 첫 진입, 온보딩 완료 후 재실행 시 메인 진입을 확인한다. |
| 스킬 테스트 | P0 | 시스템 스킬 수정이 아니라 사용자 스킬 레벨 저장으로 처리되는지 확인한다. |
| 프로젝트 생성/수정/삭제 | P0 | 생성 후 앱 재실행 유지는 자동화 완료. 수정/삭제, 서버 DB 반영, 오프라인 후 재동기화는 추가 확인한다. |
| 작업공간 | P0 | RowCounter, RowInstruction, WorkSession 저장/삭제가 재실행 후 유지되는지 확인한다. |
| 게이지 | P1 | GaugeRecord/GaugeTarget 생성, 수정, 삭제, 앱 재실행 후 유지 여부를 확인한다. |
| 계정 전환 | P1 | A 계정 데이터가 B 계정에서 보이지 않는지 확인한다. |
| 서버 OFF | P1 | cache 있음/없음에 따라 fallback 또는 오프라인 안내가 맞게 보이는지 확인한다. |
