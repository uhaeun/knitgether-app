## 시스템 피커/카메라/공유시트 의존 — 실기기 수동 확인 대상
아래 경로는 당시 사용한 스크립트로 실행하지 못해 추가 확인 대상으로 남겼습니다. 시스템 UI 전체가 자동화 불가능하다는 의미는 아닙니다.
- 도안 PDF 가져오기 / 문서 스캔 (파일 피커 / 카메라)
- 진척 사진 (카메라 / 사진 피커)
- 데이터 백업 내보내기, 가져오기 (공유 시트 / 파일 피커)
