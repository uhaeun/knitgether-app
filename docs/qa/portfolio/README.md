# 테스트 설계와 수행 기록

최초 테스트의 기대 결과와 판정, 이후 수정·재검증의 연결을 확인하는 문서입니다. 대표 사례는 [QA 포트폴리오](../submission/github-guide.md), 현재 실행 결과는 [QA 문서 목차](../README.md)에서 볼 수 있습니다.

- [기능 기준](02_functional_spec.md), [리스크](03_quality_risk_map.md), [검증 전략](04_test_strategy.md)
- [테스트 설계](05_test_cases.md), [케이스·RTM](09_test_case_master.md)
- [수동 수행](06_manual_execution.md), [API·네트워크·SQL 확인](07_api_and_network.md)
- [결함 대장](10_defect_catalog.md), [자동화 코드 안내](13_automation_showcase.md)
- `evidence/`: 최초 수동 수행 화면과 당시 추적표

각 문서는 본문에 적힌 날짜·빌드의 기록입니다. 과거 실패를 최신 통과 결과로 덮어쓰지 않았으며, 설계·실행·회귀 수를 합산하지 않습니다. 과거 배경 설명, 도구 비교, 지표와 릴리즈 검토 문서는 [보존 이력](../history.md)에 연결했습니다.
