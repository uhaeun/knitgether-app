# 테스트 설계와 최초 수행

기대 결과를 정하고, TC를 수행해 최초 결함을 판정한 기록입니다. 수정 후 결과는 [주요 사례](../submission/github-guide.md)와 [실행 기록](../README.md)에 연결했습니다.

| 확인할 내용 | 문서 |
|---|---|
| 기능별 기대 결과 | [기능 기준](02_functional_spec.md) |
| 사용자 영향과 발생 가능성에 따른 우선순위 | [위험 선정](03_quality_risk_map.md) / [전략](04_test_strategy.md) |
| 사전 상태, 조작, 기대 결과와 확인 데이터 | [TC 설계](05_test_cases.md) / [TC와 요구사항 연결](09_test_case_master.md) |
| 최초 판정과 화면, API, DB 대조 | [수동 수행](06_manual_execution.md) / [API와 네트워크](07_api_and_network.md) |
| 결함의 발견, 수정과 재검증 이력 | [결함 대장](10_defect_catalog.md) |
| 테스트 코드와 실행 환경 | [자동화 안내](13_automation_showcase.md) |

`evidence/`에는 최초 수행 화면과 당시 추적표가 있습니다. 판정과 수치는 각 문서에 적힌 날짜와 빌드를 기준으로 읽습니다. `01`, `08` 같은 과거 문서 번호는 [보존 이력](../history.md)의 원문 목차에서 찾을 수 있습니다.
