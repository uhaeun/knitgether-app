## 리스크 등급

| 등급 | 기준 | 예시 |
|---|---|---|
| Critical | 앱 사용 시작 불가, 계정 생성 불가, 저장 데이터 유실, 계정 간 데이터 노출 | 회원가입 실패, 프로젝트/작업 기록 유실 |
| Important | 핵심 기능 일부 실패, offline retry 실패, 오류 메시지 부정확 | 서버 OFF 후 cache fallback 실패 |
| Minor | 기능은 가능하지만 UX/문구/정렬/표시가 어색함 | 성공 메시지 위치, 빈 상태 문구 |
