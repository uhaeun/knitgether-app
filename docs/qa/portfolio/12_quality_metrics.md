# 과거 QA 지표 집계

이 문서는 여러 시점의 설계·결함·실행 결과를 다시 모은 집계였습니다. 별도로 수행한 검증 결과는 아닙니다.

- 결과와 판정 정정: [회차별 실행 기록](11_execution_results.md)
- 결함 수·발견 경위·수정 상태: [결함 대장](10_defect_catalog.md)
- 테스트 ID와 실행 항목: [케이스 목록](09_test_case_master.md)
- 코드 구성과 검사 한계: [자동화 안내](13_automation_showcase.md)

수집된 항목 수, 실제 수행 수와 PASS 수는 서로 다릅니다. 시점이 다른 집계는 합쳐 쓰지 않습니다.

[시점·빌드·출처를 포함한 집계 원문](https://github.com/uhaeun/knitgether-app/blob/96f5b84e2feda41f22edf9400536d48a36c9c5dc/docs/qa/portfolio/12_quality_metrics.md)을 보존했습니다. 미측정 지표와 당시 확인하지 못한 검출력도 원문에 남아 있습니다.
