## 1. 헤드라인 [확정 9/1]

기획과 QA에 비중을 두고, 개발은 AI에게 맡긴 iOS 앱 프로젝트다. 기능을 먼저 명세하고, 그 명세를 기준으로 삼아 AI가 만든 코드를 QA했다. 사람이 리뷰하지 않은 코드에서 무엇이 깨지는지를 문서화된 기준과 실측으로 확인한 기록이다. 산출물은 앱이 아니라 QA 과정 전체다.
