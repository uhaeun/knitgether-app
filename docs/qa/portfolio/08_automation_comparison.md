# 자동화 도구 검토 기록

XCUITest는 카운터 결함의 단건 회귀에, Appium은 여러 화면의 반복 검사에 사용했습니다. 같은 조건으로 두 도구를 비교한 실험이 아니므로 속도·안정성의 우열을 주장하지 않습니다.

현재 코드 구성과 실행 방법은 [자동화 안내](13_automation_showcase.md), 당시 실패와 환경 문제의 분석은 [실행 결과](11_execution_results.md)와 [스위트 작업 기록](../appium_suite_worklog_2026-08-27.md)에 있습니다.

[비교·결함 주입 실험·환경 분석 원문](https://github.com/uhaeun/knitgether-app/blob/96f5b84e2feda41f22edf9400536d48a36c9c5dc/docs/qa/portfolio/08_automation_comparison.md)은 당시 기록으로 보존했습니다. 원문에 적힌 숫자는 해당 버전의 결과입니다.
