skipped 1건은 UI-42b 실기기 문서 스캔이고 자동화 비용이 검증 가치를 넘는다는 판단으로 수동에 남겼다.

증거는 네 축으로 나뉘고 각각 다른 것을 증명한다.

| 무엇을 증명하는가 | 방법 | 결과 |
| --- | --- | --- |
| 스위트 안정성 | 전체 2회 연속 실행 | 동일 결과 |
| 케이스 간 격리 | 파일과 케이스 순서를 뒤집어 실행 | 동일 결과 |
| 검출력 | 결함 6종 주입 대조 | 6종 전건 검출, 과잉 결합 0건 |
| 전제 의존성 | Given 제거 음성 대조 | 검출력 없는 케이스 0건 |

전건 통과만으로는 제품이 정상인지 테스트가 아무것도 보지 않는지 구분되지 않는다. 위 표의 검출력과 전제 의존성 두 줄이 그 구분을 만든다. 상세는 `docs/qa/appium_suite_worklog_2026-08-27.md` 2절과 3절에 있다.
