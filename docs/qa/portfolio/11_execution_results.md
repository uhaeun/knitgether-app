## 3. 트랙 A의 기록 공백 (QA 판단 필요)

집계는 트랙 A를 **실행 4, PASS 3, FAIL 1**로 적는다. 그런데 판정이 기록된 것은 CUJ1, CUJ2, CUJ4 세 건뿐이다.

- 05에 `TC-CUJ3-01 연결의 생애주기`가 설계돼 있다 (05_test_cases.md:105)
- 06 본문에 TC-CUJ3-01이라는 문자열이 없다. PASS 판정 요약표에도, FAIL 결함 리포트에도 없다
- 시트 `1차 사이클 결과` 탭도 20행이며 TC-CUJ3-01 행이 없다
- 06은 "트랙 A 나머지 1건과 실행 기록 전문은 06 문서가 정본"이라고 적었으나, 그 1건이 06 본문에 없다

즉 **집계상 FAIL 1건의 근거가 어느 문서에도 남아 있지 않다.** 판정 자체가 안 됐는지, 판정은 했는데 기록이 노션 관찰 로그에만 있는지, 집계 숫자가 틀린 것인지는 실행자만 안다.

포트폴리오에서 이건 그냥 두면 안 되는 종류다. 21건과 FAIL 9건은 최종 페이지 2번 섹션의 실측 숫자로 나갈 값이고, 그중 한 건의 근거가 비어 있으면 나머지 숫자의 신뢰도까지 같이 떨어진다.

**세 갈래 중 하나로 정리할 것**
1. 노션 관찰 로그(8/4 트랙 A)에 판정이 있으면 → 그 근거를 06과 이 문서에 옮기고 FAIL이면 결함 번호 부여
2. 실행은 했는데 판정을 못 남겼으면 → 재실행 후 판정
3. 실행 안 했으면 → 집계를 실행 20, PASS 12, FAIL 8로 정정하고 TC-CUJ3-01을 미실행으로 표기
